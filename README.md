GD compression implentated by link/to/github/repo 
The method has been adapted to the specific task of the project. 

PURPOSE: Starting from an Image dataset (RAW_IMG), the idea is to obtain a representation (INPUT_IMG) of the compressed file (COMPR_IMG).
The INPUT_IMG is therefore used as input for a neural network model, trying to determine the right class to which the image belongs. 
This process could result as a good starting point for obtaining a faster training and evaluation, reducing the overall parameters of the network
and also lighter overload of the machine.
